最稳妥的 `scan()` 逻辑是：

> 每一轮循环只完成一件事：从 `index` 开始识别一个完整单词，并把 `index` 移到下一个尚未处理的字符。

不要像当前代码一样，识别完标识符后又继续执行符号识别。

整体流程：

```text
跳过空白
   ↓
是否到达文件末尾？——是→结束
   ↓
根据当前字符选择一种扫描方式
   ├─ 字母或下划线 → 标识符/关键字
   ├─ 数字         → 整数常量
   ├─ 单引号       → 字符常量
   ├─ 双引号       → 字符串常量
   ├─ 运算符/界符  → 符号
   └─ 其他字符     → 错误处理
   ↓
continue，回到循环开始
```

推荐写成这种结构：

```cpp
void Lexer::scan()
{
    while (index < length)
    {
        // 1. 跳过空格、换行、Tab
        skipSpace();

        // skipSpace 之后可能已经到达文件末尾
        if (index >= length)
        {
            break;
        }

        char current = s[index];

        // 2. 标识符或者关键字
        if (isalpha(static_cast<unsigned char>(current)) || current == '_')
        {
            scanIdentifier();
            continue;
        }

        // 3. 整数常量
        if (isdigit(static_cast<unsigned char>(current)))
        {
            scanInteger();
            continue;
        }

        // 4. 字符常量
        if (current == '\'')
        {
            scanChar();
            continue;
        }

        // 5. 字符串常量
        if (current == '"')
        {
            scanString();
            continue;
        }

        // 6. 运算符和分隔符
        scanSymbol();
    }
}
```

这里最重要的是每个分支最后都有 `continue`。

### 1. 空白字符

```cpp
void Lexer::skipSpace()
{
    while (index < length)
    {
        if (s[index] == ' ' || s[index] == '\t' || s[index] == '\r')
        {
            index++;
        }
        else if (s[index] == '\n')
        {
            line++;
            index++;
        }
        else
        {
            break;
        }
    }
}
```

并且构造函数中：

```cpp
this->line = 1;
```

### 2. 标识符和关键字

首先完整读取：

```text
字母、数字、下划线
```

然后再查关键字表：

```cpp
void Lexer::scanIdentifier()
{
    int start = index;

    while (index < length &&
           (isalnum(static_cast<unsigned char>(s[index])) ||
            s[index] == '_'))
    {
        index++;
    }

    string word = s.substr(start, index - start);

    auto it = keyWords.find(word);

    if (it != keyWords.end())
    {
        tokens.emplace_back(it->second, word, line);
    }
    else
    {
        tokens.emplace_back(TokenType::IDENFR, word, line);
    }
}
```

例如：

```text
int       → INTTK
main      → MAINTK
integer   → IDENFR
abc_123   → IDENFR
```

### 3. 整数常量

```cpp
void Lexer::scanInteger()
{
    int start = index;

    while (index < length &&
           isdigit(static_cast<unsigned char>(s[index])))
    {
        index++;
    }

    string number = s.substr(start, index - start);
    tokens.emplace_back(TokenType::INTCON, number, line);
}
```

不要立刻用 `stoi()` 替代原字符串，因为课程要求原样输出。例如 `0012` 应保存为 `"0012"`。

### 4. 字符和字符串

关键是把左右引号都包含进去：

```cpp
void Lexer::scanString()
{
    int start = index;

    index++; // 跳过左双引号

    while (index < length && s[index] != '"')
    {
        if (s[index] == '\n')
        {
            line++;
        }

        index++;
    }

    if (index < length)
    {
        index++; // 把右双引号也包含进去
    }

    string value = s.substr(start, index - start);
    tokens.emplace_back(TokenType::STRCON, value, line);
}
```

字符常量的思路相同：

```cpp
void Lexer::scanChar()
{
    int start = index;

    index++; // 左单引号

    while (index < length && s[index] != '\'')
    {
        index++;
    }

    if (index < length)
    {
        index++; // 右单引号
    }

    string value = s.substr(start, index - start);
    tokens.emplace_back(TokenType::CHARCON, value, line);
}
```

于是：

```c
'A'
"\n"
```

能够原样输出：

```text
CHARCON 'A'
STRCON "\n"
```

### 5. 运算符和分隔符

必须先尝试两个字符的符号，再尝试单字符：

```cpp
void Lexer::scanSymbol()
{
    // 优先检查两个字符
    if (index + 1 < length)
    {
        string two = s.substr(index, 2);

        auto it = symbols.find(two);
        if (it != symbols.end())
        {
            tokens.emplace_back(it->second, two, line);
            index += 2;
            return;
        }
    }

    char current = s[index];

    // 单独的 & 或 | 是 a 类错误
    if (current == '&' || current == '|')
    {
        errors.emplace_back(ErrorType::IllegalSymbol, line);
        index++;
        return;
    }

    // 再检查单字符符号
    string one(1, current);
    auto it = symbols.find(one);

    if (it != symbols.end())
    {
        tokens.emplace_back(it->second, one, line);
        index++;
        return;
    }

    // 无法识别的字符也必须向后移动，防止死循环
    index++;
}
```

先判断双字符非常重要：

```text
<= 不能拆成 < 和 =
>= 不能拆成 > 和 =
== 不能拆成 = 和 =
!= 不能拆成 ! 和 =
&& 不能拆成两个 &
|| 不能拆成两个 |
```

你现在的 `getSymbol()` 已经有“先双字符、再单字符”的雏形，可以保留；核心是重新组织 `scan()`，让每个分支只识别一种 Token。

最终建议把 `Lexer` 拆成这些小函数：

```cpp
void skipSpace();
void scanIdentifier();
void scanInteger();
void scanChar();
void scanString();
void scanSymbol();
```

这样 `scan()` 本身只负责“看当前字符，决定调用谁”，不会把所有细节混在一个大循环里。这个结构后面加入注释处理、语法分析和错误恢复也比较容易。

## 14. 助手

`'a"` 是一个不合法的字符常量：左边是单引号，右边却是双引号。

但需要区分两件事：

1. 课程要求必须处理的错误；
2. 为了程序健壮性额外处理的异常输入。

这次词法分析作业明确列出的词法错误只有：

```text
单独的 & → a
单独的 | → a
```

因此遇到 `'a"` 时，不能擅自输出：

```text
1 a
```

因为 `a` 不是“字符常量引号错误”，而是专门表示把 `&&` 或 `||` 写成单个符号。

比较合理的处理方式是：

```cpp
void Lexer::scanChar()
{
    int startLine = line;
    int start = index;

    index++; // 跳过左单引号

    // 没有字符内容
    if (index >= length || s[index] == '\n')
    {
        // 内部记录：字符常量不完整
        return;
    }

    // 读取字符内容
    if (s[index] == '\\' && index + 1 < length)
    {
        index += 2; // 转义字符，例如 '\n'
    }
    else
    {
        index++; // 普通字符，例如 'a'
    }

    // 正常情况下，现在必须是右单引号
    if (index < length && s[index] == '\'')
    {
        index++;

        string value = s.substr(start, index - start);
        tokens.emplace_back(TokenType::CHARCON, value, startLine);
        return;
    }

    // 没有找到右单引号：这是畸形字符常量
    // 不能记录为课程中的 a 类错误
    // 最重要的是保证 index 已经移动，程序不会死循环
}
```

对于输入：

```text
'a"
```

执行过程是：

```text
读取 '    → 认为字符常量开始
读取 a    → 字符内容
期待 '    → 实际遇到 "
判定为畸形字符常量
```

此时不生成 `CHARCON`，也不应该向 `error.txt` 写 `a`。

本次作业可以采取的策略是：

- 对课程规定的单独 `&`、`|`：写入 `error.txt`，错误码为 `a`；
- 对 `'a"` 这种题目没有规定错误码的输入：保证程序不越界、不死循环，但不向 `error.txt` 伪造错误码；
- 平台测试通常不会提供题目未定义如何处理的错误。

所以 `scan()` 的通用底线是：

> 无论输入多奇怪，每个分支要么成功识别一个 Token，要么至少让 `index` 向后移动，绝不能卡在同一个字符上。
